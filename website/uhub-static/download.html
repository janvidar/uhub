Download

Get the source code and build uhub on your platform of choice.

Source code (Git)

The official source tree is hosted on GitHub. Clone the repository with:

git clone https://github.com/janvidar/uhub.git

Then follow the compiling guide to build it.

Debian & Ubuntu packages

Pre-built packages for Debian and Ubuntu based distributions are provided through a PPA maintained by tehnick.

uhub PPA →

Releases

The latest stable release is uhub 0.8.1, a security release — see the news. Tagged releases are published on the GitHub releases page; download the attached uhub-<version>-src.tar.gz, not GitHub's automatic "Source code" archives, which lack the bundled submodules and will not build. Older binary builds are kept in the build archive.
