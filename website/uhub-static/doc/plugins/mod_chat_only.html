mod_chat_only

Run a chat-only hub. Part of the bundled plug-ins.

mod_chat_only turns the hub into a pure chat hub: it denies file searches, search results and peer-to-peer connection setup (both active and passive), so users can talk but not set up transfers through the hub. It takes no configuration string — just load it: 

plugin /var/lib/uhub/mod_chat_only.so

Behaviour

The first time a user searches, or a client attempts to set up a transfer, the hub sends a one-time notice (“Searching is disabled. This is a chat only hub.” or “Connection setup denied. This is a chat only hub.”); further attempts are denied silently.

Operators and above are exempt and may still search and set up transfers. Search results are denied for everyone, since a result is only ever a reply to a search that was itself allowed.

Fixed in 0.8.0: the operator exemption was never initialised in earlier versions, so operators were restricted along with everyone else.

This is the plug-in form of a chat-only hub — there is no core chat_only configuration directive. To instead restrict who may talk rather than disable transfers, use the core chat_is_privileged option or, for per-credential control including private messages, mod_chat_is_privileged.

A JavaScript port of this plug-in ships as doc/js/chat_only.js — see the JavaScript plug-in API.
