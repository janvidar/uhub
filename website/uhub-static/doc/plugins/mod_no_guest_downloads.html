mod_no_guest_downloads

Restrict downloads to registered users. Part of the bundled plug-ins.

mod_no_guest_downloads lets guests chat, but reserves searching and file transfers for registered users: only users with a registered account (or higher) may search, receive search results and set up connections. It takes no configuration string — just load it: 

plugin /var/lib/uhub/mod_no_guest_downloads.so

This is useful for a public chat hub that still offers file sharing as a perk of registering. To disable transfers for everyone instead, use mod_chat_only.
