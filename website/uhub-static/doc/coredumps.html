Core dumps

Capture a crash so it can be debugged.

On Linux, enable core dumps before starting uhub:

$ ulimit -c unlimited
$ uhub

If uhub crashes, a file called core is written to disk. This can be used to debug the problem further. Please compress both the core file and the uhub binary: 

tar czvf coredump.tar.gz uhub core

Then file a bug report and attach coredump.tar.gz in the bug tracker.
